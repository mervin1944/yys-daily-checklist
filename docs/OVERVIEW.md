# 项目概述

## 背景

阴阳师每天有一堆固定的日常/周常任务(探索、御魂、御灵、契灵、悬赏封印、寮任务、斗技等),游戏内没有一个跨设备、可自定义的勾选清单,容易漏做。这个项目就是给自己/社区做一个轻量的待办工具。

## 设计取舍

- **纯前端、零服务器成本**:不做账号系统和后端,数据只存在浏览器本地(IndexedDB)。换设备/清浏览器数据会丢失记录,这是刻意的取舍——换来的是任何人都能白嫖 GitHub Pages 免费部署一份,不需要谁来出服务器钱。
- **PWA 而不是原生 App**:一套代码覆盖网页 + "添加到主屏幕"的类 App 体验,不需要上架应用商店、不需要开发者账号。后续如果真的需要原生包,可以用 Capacitor 把现有代码壳化成 Android/iOS,几乎不用重写。
- **周期重置用"周期 key 比较"而不是后台定时任务**:每个任务记录"最后勾选时所属的周期"(比如日期字符串),渲染时和当前周期比较,不一致就视为未完成。好处是不需要常驻定时逻辑,页面关掉再打开也能正确判断有没有跨过重置点。详见 `src/lib/resetCycle.ts`。
- **任务模板可自定义**:游戏版本会不断加新副本、下线旧内容,预置的任务只是初始参考模板,增删改查都做在 UI 里,不需要改代码。

## 技术栈

React 18 + Vite + TypeScript + Tailwind CSS + Dexie(IndexedDB 封装)+ Zustand + vite-plugin-pwa,GitHub Actions 自动构建部署到 GitHub Pages。

## 已知限制

- 不支持多设备数据同步(见上面的设计取舍)
- 重置时间点固定按玩家本机时间的 5:00 / 周一 5:00 计算,没有做时区/自定义重置时间的设置项
- 拖拽排序目前是简单的上下移按钮,还没接入真正的拖拽库
